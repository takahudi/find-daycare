# 絞り込みと選択中の施設を URL で共有する

利用者が同じ条件と施設を開けるよう、React SPA 用の nuqs アダプターで URL を状態として扱う。共有済みリンクの意味を保つため、次のキーと値を公開形式とする。

| 状態 | キー | 値 | 省略時 |
| --- | --- | --- | --- |
| 区 | `ward` | 区 ID のカンマ区切り（データ順） | すべての区 |
| クラス年齢 | `age` | 0〜5 のカンマ区切り（昇順） | 指定なし |
| 施設種別 | `type` | `nursery,kodomoen,community,kigyo` の順のカンマ区切り | すべての種別 |
| 空きのみ | `open` | `1` | オフ |
| 並び順 | `sort` | `distance`、`vacancy`、`name` | 自宅があれば距離順、なければ空きが多い順 |
| 選択中の施設 | `facility` | データにある施設 ID | 指定なし |

既定値は省略し、操作時は履歴を `replace` する。区・施設種別の空文字は選択0件を表す。不正な値は捨て、既知の値がなければ既定に戻す。自宅がないときの `sort=distance` は空きが多い順として扱う。施設を復元したら地図を移動し、対応するカードまでスクロールする。モバイルの表示タブは共有しない。

自宅の位置と住所入力は [ADR 0002](0002-home-location-never-leaves-device.md) に従い URL に含めない。自宅は localStorage にだけ保存する。そのため距離順の共有結果は、開く端末の自宅の有無と位置によって変わる。

読み込み時の絞り込みで一覧にない施設を `facility` が指す場合は、未選択にして URL から `facility` を消す。条件を広げてもその選択は復元しない。表示中の条件と選択の不一致を残さないためである。

`sort` を省いた URL は、開いた端末の既定（自宅があれば距離順）に従う。そのため自宅を解除すると、従来の距離順の保持から空きが多い順へ変わる。この変更を受け入れ、端末の既定との対応を優先する。自宅の解除後などに既定と同じ `sort=vacancy` が残ることも受け入れ、既定が変わるだけでは URL を書き換えない。
