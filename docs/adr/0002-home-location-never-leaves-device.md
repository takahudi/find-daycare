# 自宅の位置を外部に出さない

利用者が入力する自宅の住所は、個人を特定できる情報になる。そのため、自宅の位置が利用者の端末と自前の配信元の外に出ないようにする。

- **住所検索**：国土地理院の住所検索APIは使わない。国土交通省「位置参照情報」（町丁目・街区）の大阪市分をビルド時に辞書にし、端末の中で照合する。以前の実装では、町名だけの入力1回につき最大25件の問い合わせをブラウザから地理院へ送っていた。
- **地図タイル**：Protomaps（OpenStreetMap）から大阪市の範囲だけを切り出したPMTilesを、アプリと同じWorkerがR2から配信する。外部のタイルサーバーを使うと、自宅の付近を拡大した時点で閲覧位置が第三者に伝わる。
  フォントとアイコン画像は小さく、ビルドごとに版をそろえるため、R2ではなくWorkerの静的アセットとして配信する。
- **URL**：絞り込みと選択中の施設はURLに載せて共有できるようにする。自宅は載せず、`localStorage` にだけ保存する。

その代わりに、番地より細かい精度は得られず、位置参照情報と地図データを年に1回程度、手作業で更新する手間が増える。地図の見た目も地理院の淡色地図からOpenStreetMap系に変わる。

## Considered Options

- **Worker経由で地理院APIを呼び、結果をキャッシュする**：変更は小さく済むが、住所は第三者に送られ、外部APIへの依存も残る。
- **地理院ベクトルタイルを直接使う**：申請は不要だが、閲覧位置が外部に伝わる。
