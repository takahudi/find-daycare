# データ更新は自動化せず、ローカルで実行してPRにする

空き情報は毎月更新されるが、取得から公開までを自動化しない。`data:update` はローカルで実行し、生成結果の差分を目視で確認してからPRにする。CIが担当するのはスキーマと不変条件の検証だけ。

理由は3つある。
- 施設の基本情報PDFには自動で抽出できない様式があり、目視で転記して `manual-details.json` に残している。
- ビルド時に出る警告（区の公表値とCSVの食い違いなど）を人が判断する必要がある。
- 市のサイトにはレート制限があるため、取得は1区ずつ確認しながら進めている。

定期実行で取得してPRまで自動で作る案（GitHub Actions）は、運用が安定したら追加を検討する。
